# 显示器挂灯 DIY 制作方案（个人自制版）

> 目标：一个人在家做出来。所有零件都能在淘宝 / 拼多多零售买到，不开模、不打 PCB、不写代码。
> 前提：会用电烙铁焊导线；有一台装了 Chrome 或 Edge 浏览器的电脑；买一个 USB 电流表（用来确认整灯不超过 900 mA）。
> 价格为参考价，以实际购买为准。

---

## 0. 一页看懂

**做法**：用现成挂灯的外壳和重力夹，里面换成自己焊的一套小电路。

- **主控**：ESP32-C3 SuperMini 小板，刷开源固件 **WLED**。手机浏览器或 WLED App 控制，自带灯效、场景、定时、夜灯，不用写代码。
- **前光**：5V 双色温 COB 灯带（Ra ≥ 90），两颗 MOS 管分别调暖白和冷白。
- **背光**（可选）：WS2812B 灯带，贴在灯体背面。
- **按键**：两个 TTP223 触摸模块，藏在塑料堵头里面；另留一个接口可以接实体按钮。
- **供电**：Type-C 母座小板。用自恢复保险丝、限流电阻和 WLED 限流三层控制电流，再用 USB 电流表实测确认 ≤ 900 mA。

| 项目 | 估计 |
|---|---|
| 零件费用 | ¥110–200（含一个 ¥30–60 的平价挂灯当外壳） |
| 工具（家里没有的话） | ¥150–250（电烙铁、万用表、USB 电流表、热熔胶枪等） |
| 制作时间 | 零件到齐后一个周末：刷机配置 1 h、桌面试接 1–2 h、装壳 3–5 h、调试 1 h |
| 难度 | 中等偏易：主要是焊导线；有两颗小贴片 MOS 管，不想焊贴片可以换成品模块 |

**原需求三条提问的 DIY 答案**

1. **夹具**：直接用成品挂灯的重力夹（自带防滑软垫和阻尼转轴），不自己做。实在买不到合适外壳，才用 3D 打印。
2. **氛围灯**：能做，贴在灯体背面、朝后上方 30–45°。WLED 把它限制在约 150 mA，另有 0.25 A 自恢复保险丝兜底，整灯不会超过 900 mA；这个亮度当背景光够用。不想折腾可以先不装，以后再补。
3. **触摸 / 蓝牙**：TTP223 触摸模块约 ¥1 一个。手机控制用 ESP32-C3 自带的 Wi-Fi，不需要额外的蓝牙模块，也不一定要装 App。**注意：WLED 不支持蓝牙控制**，手机要和灯连同一个 2.4 GHz Wi-Fi。

## 2. 外壳和重力夹（三选一）

### 方案 A：买一个平价成品挂灯拆来用（推荐，一定买得到）

- 淘宝 / 拼多多搜“显示器挂灯 USB”“屏幕挂灯 重力夹”，¥30–60。
- 挑选要点：
  - 是**重力夹**（挂在屏幕上沿、后面有配重臂），不是弹簧夹；
  - 灯头能转动（有阻尼转轴）；
  - 外壳是铝合金，长度 40–50 cm，越接近 45 cm 越好；
  - 堵头用螺丝固定（看商品图里堵头上有没有螺丝孔），这样好拆；
  - 外壳截面越粗越好（≥ 20 mm），里面才放得下主控板。
- 拆开后：**保留**外壳、灯罩、堵头、夹子和转轴；**拆掉不用**原来的灯板和电路板。
- 先挂到自己的显示器上试一下合不合适，再动手改。

### 方案 B：买“屏幕挂灯外壳套件”

- 淘宝 / 1688 搜“屏幕挂灯外壳”“显示器挂灯 外壳套件”“挂灯 公模 外壳”。
- 如果有卖空壳套件（铝壳 + 灯罩 + 堵头 + 重力夹），尺寸更规整、内部更好排线。
- 是否有现货、能不能单件购买，要问商家。

### 方案 C：通用 LED 铝槽 + 3D 打印夹具（最自由）

- 铝槽：搜“LED 铝槽 乳白罩 堵头”，选内宽 ≥ 18 mm、深 ≥ 12 mm 的 U 型槽，让商家切 45 cm。
- 夹具：在 MakerWorld 搜 “monitor light bar”，找配重式（counterweight）夹具模型，下载 STL 交给淘宝 3D 打印店，用 PETG 或 PLA 打印，约 ¥20–40。
- 转轴：M4 螺丝 + 尼龙防松螺母 + 两片橡胶垫片，螺母拧多紧就是阻尼多大。
- 夹子内侧贴硅胶防滑垫；后臂里塞几个钢垫片当配重。

## 4. 电路与接线

### 4.1 接线总图

```text
                       ┌──────────────────────── 5V 母线 ────────────────────────┐
USB-C 母座 5V ──[自恢复 1.1A]──┤                                                    │
(带 5.1kΩ)                     ├──(+) 470µF (−)── GND                                │
    GND ── 公共地              ├──[1N5819 ▶|]──────────────── ESP32-C3 的 5V 脚     │
                               ├──[自恢复 0.25A]──[1N4007 ▶|]── 背光 WS2812B 的 5V   │
                               └──[限流电阻 0–1.8Ω 1W]────────── 前光 COB 灯带的 +   │

前光 COB 暖(−) ── Q1 漏极 D │ Q1 源极 S ── GND │ Q1 栅极 G ──100Ω── GPIO4，G 另接 10kΩ 到 GND
前光 COB 冷(−) ── Q2 漏极 D │ Q2 源极 S ── GND │ Q2 栅极 G ──100Ω── GPIO5，G 另接 10kΩ 到 GND
背光 WS2812B DIN ──330Ω── GPIO3        背光 WS2812B GND ── GND
触摸 1（TTP223）：VCC ── 3V3   I/O ── GPIO6   GND ── GND
触摸 2（TTP223）：VCC ── 3V3   I/O ── GPIO7   GND ── GND
实体按钮（可选）：GPIO10 ── 轻触开关 ── GND

所有 GND 接在一起。二极管有色环的一头（负极）朝向负载。
```

### 4.2 ESP32-C3 引脚分配

| 引脚 | 接到 | 说明 |
|---|---|---|
| 5V | 1N5819 负极（正极接 5V 母线） | 主控供电 |
| GND | 公共地 | — |
| 3V3 | 两个 TTP223 的 VCC | 触摸模块用 3.3 V 供电，输出电平才不会超过主控耐压 |
| GPIO3 | 330 Ω → 背光 DIN | 背光数据线 |
| GPIO4 | 100 Ω → Q1 栅极 | 暖白（WLED 里 PWM CCT 的第 1 个引脚） |
| GPIO5 | 100 Ω → Q2 栅极 | 冷白（第 2 个引脚） |
| GPIO6 | 触摸 1 的 I/O | — |
| GPIO7 | 触摸 2 的 I/O | — |
| GPIO10 | 轻触开关，另一端接 GND | 可选 |
| **不要用** | GPIO2、8、9（和启动有关）、20、21（串口） | GPIO8 上还有板载指示灯 |

AO3400 引脚（SOT-23）：1 = 栅极 G，2 = 源极 S，3 = 漏极 D（单独一边的那只脚是 D）。

**如果用 D4184 模块代替 AO3400**：模块的 PWM 输入接 GPIO4 / GPIO5，输入 GND 接地；VIN+ / VIN− 接 5V 和 GND；OUT− 接灯带的暖 / 冷负极。**灯带的 + 要从限流电阻那一路接，不要接模块的 OUT+**（OUT+ 直通 5V，会绕过限流电阻）。

### 4.3 每个零件为什么要装

| 零件 | 作用 |
|---|---|
| Type-C 母座上的 5.1 kΩ | 告诉充电头“我要 5V”。没有它，C-to-C 线插充电头不会出电 |
| 自恢复保险丝 1.1 A | 短路时自动断开，冷却后恢复 |
| 限流电阻 | 给前光定死最大电流，这就是**硬件限流**；阻值由实测决定（见 §5） |
| 1N5819 | 刷机时用电脑给主控供电，防止电脑和外部电源互相倒灌，也防止电脑去带动灯带 |
| 自恢复保险丝 0.25 A | 万一固件失灵、背光全白最亮，会自动断开，冷却后恢复 |
| 1N4007 | 把背光供电降到约 4.2 V。WS2812B 在 5V 供电时，3.3 V 的数据信号处在临界值，容易乱闪；降压后就稳了 |
| 470 µF 电容 | 吸收 Wi-Fi 发射时的电流尖峰，防止主控重启 |
| 100 Ω + 10 kΩ | 100 Ω 保护引脚；10 kΩ 保证上电瞬间前光不乱亮 |
| 330 Ω | 减少背光数据线上的振铃，保护第一颗灯珠 |

## 5. 功率预算和电流实测

### 5.1 预算

| 部分 | 电流 | 怎么保证 |
|---|---|---|
| ESP32-C3 + Wi-Fi | 约 100–120 mA | 实测 |
| 触摸模块 × 2 | < 1 mA | — |
| 前光（最亮） | **≤ 550 mA** | 限流电阻定死（硬件）；WLED 的 CCT blending 保持 0%，中间色温时两路交替点亮，电流不会翻倍 |
| 背光（最亮） | **≤ 150 mA** | WLED 限流（固件）+ 0.25 A 自恢复保险丝（硬件兜底） |
| **合计** | **≤ 820 mA（约 4.1 W）** | 低于 900 mA ✓ |

- **不装背光**的话，前光上限可以放到约 700 mA，亮约 25%。
- **亮度预期**：前光约 2.7 W，灯下 45 cm 中心大约 300 lx 上下，看书写字够用，比 5 W 以上的商用挂灯暗一些。这是 5V/900 mA 这个供电条件决定的。

### 5.2 实测方法（USB 电流表串在充电头和灯之间）

| 第几步 | 状态 | 记录 | 合格 |
|---|---|---|---|
| 1 | 灯全关（Wi-Fi 连着） | 待机电流 I₀ | 约 80–130 mA |
| 2 | 前光 100%，色温拉到最暖 | I_暖 | — |
| 3 | 前光 100%，色温拉到最冷 | I_冷 | — |
| 4 | 前光电流 = max(I_暖, I_冷) − I₀ | — | ≤ 550 mA |
| 5 | 前光最亮 + 背光彩虹最亮 | 总电流 | ≤ 850 mA |

### 5.3 前光超了怎么办：串限流电阻

5V 灯带内部是“LED + 电阻”的结构，在正极串一个小电阻就能把电流压下来。估算公式（单位 A、Ω）：

> **R ≈ 2.1 ÷ I目标 − 2.1 ÷ I实测**

| 实测前光电流 | 目标 550 mA 需要的电阻 | 选用 |
|---|---|---|
| 650 mA | ≈ 0.6 Ω | 0.47 Ω |
| 800 mA | ≈ 1.2 Ω | 1 Ω（或 1 Ω + 0.22 Ω 串联） |
| 1000 mA | ≈ 1.7 Ω | 1.5 Ω |

- 实测已经 ≤ 550 mA 就不用电阻，用一根线短接即可。
- 装上电阻后**再测一次**，公式只是估算，以实测为准。
- 电阻会发热（约 0.3 W），用 1 W 规格、套热缩管，别贴着塑料件。
- 偷懒的办法：WLED 里把 Global brightness factor（全局亮度系数）调低到 80–90%。但这属于固件限流，而且背光也会一起变暗。

### 5.4 供电注意

- **最稳的是 5V / 1A 以上的手机充电头**。快充头也没关系：这个灯不会和充电头协商快充，只会拿到 5V。
- 显示器上的 USB 口如果是 USB 2.0（一般是黑色或白色口），只能给 500 mA，开到最亮时灯可能会重启。这种情况把 Global brightness factor 调到 50% 左右，或者改插充电头。
- 关灯后 Wi-Fi 还在工作，待机约 0.5 W。不想要待机耗电，就用带开关的 USB 线。

## 6. 制作步骤

> 原则：**先在桌面上把电路全部接好、测好，再装进外壳。** 装进去以后再改会很麻烦。

### 第 1 步：给 ESP32-C3 刷 WLED（只插主控板）

1. 用数据线把 ESP32-C3 SuperMini 插到电脑（先别接任何其他东西）。
2. 用 Chrome 或 Edge 打开 `install.wled.me`，选最新稳定版（Stable），点 Install，在弹窗里选这块板子的串口，等进度走完。
3. 找不到串口：换一根能传数据的线（有些线只能充电）；或者**按住板子上的 BOOT 键再插 USB**，然后松开。SuperMini 用芯片自带的 USB，Windows 10/11 不用装驱动。
4. 刷完后，手机连 Wi-Fi 热点 `WLED-AP`（密码 `wled1234`），浏览器打开 `4.3.2.1`，进 WiFi Setup 填家里 Wi-Fi，保存。
5. 之后用 WLED App 自动搜索这盏灯，或在路由器后台的设备列表里找名字带 wled 的设备，记下 IP。
6. **连不上家里 Wi-Fi**：
   - ESP32-C3 只支持 2.4 GHz，路由器的 5 GHz 网络搜不到；
   - SuperMini 有些批次发射功率太高会掉线：在 WiFi Setup 里把 **Max. TX power** 改成 8.5 dBm 再试。

### 第 2 步：桌面试接

按 §4 接线图，在桌上用焊线或鳄鱼夹把所有东西连起来，顺序：

1. 先接 Type-C 母座 → 自恢复保险丝 → 电容 → 1N5819 → 主控，上电确认主控正常、Wi-Fi 能连。
2. 再接两个触摸模块，按 §7 配好按钮，摸一下确认有反应。
3. 再接前光灯带和两颗 MOS 管，确认能调亮度、调冷暖。
4. 最后接背光，确认颜色和效果正常。

每接一部分就上电测一次，出问题容易定位。

### 第 3 步：按 §7 把 WLED 设置好

### 第 4 步：用 USB 电流表实测，按 §5 决定限流电阻

### 第 5 步：准备外壳

- 拆下堵头，抽出灯罩，拆掉原灯板和电路板（方案 A），夹子和转轴**不要动**。
- 左堵头：用锉刀开一个和 Type-C 母座一样大的方孔（约 9 × 4 mm）。
- 外壳背面：在装背光的位置钻一个 3 mm 孔穿线，孔口打一圈热熔胶，防止割破线皮。

### 第 6 步：装前光（含防眩光）

1. 灯带在剪切标记处剪 40 cm，一端焊三根线（+、暖、冷），焊点套热缩管。
2. 用 VHB 双面胶贴在原来灯板的位置。原外壳的灯板位置本身就是为挂灯设计的角度，按原位置贴，防眩光效果最好。
3. **防眩光**：在灯罩内侧**靠屏幕的一边**，沿长度方向贴一条 4–6 mm 宽的铝箔胶带（或黑胶带），挡住射向屏幕的光。
4. 装好后关掉显示器，看黑屏上有没有一条反光带；有就把遮光条再加宽 1–2 mm。

### 第 7 步：装背光（可选）

1. 背光灯带剪 24 颗（60 灯/米对应 40 cm）。灯带上有箭头，**数据线接在箭头起点那一头**（DIN）。
2. 灯带装进 1707 小铝槽，再用 VHB 粘在灯体背面上半部，朝后上方 30–45°。角度可以用热熔胶或 3D 打印的小斜块垫出来。
3. 三根线（5V、GND、DIN）从背面的小孔穿进外壳。

### 第 8 步：装触摸模块

1. TTP223 用 VHB 双面胶贴在**塑料堵头的内侧**，正面的圆形感应区贴紧塑料，中间不能有空气隙。
2. 模块离铝壳至少 3 mm，铝壳会抢走感应信号。
3. 触摸 1 放右堵头；触摸 2 放左堵头（Type-C 口旁边）。左边放不下，就只装 1 个，其余操作用手机。
4. 上电后 1 秒内不要碰堵头（模块在自动校准）。
5. 感应不灵：在模块感应面贴一小块铜箔胶带扩大面积；误触发：在模块背面的电容焊盘焊一个 10–20 pF 电容降低灵敏度。

### 第 9 步：装主控和电源

1. 在 2 × 3 cm 洞洞板上焊电源分配：自恢复保险丝、470 µF 电容、1N5819、0.25 A 保险丝 + 1N4007、限流电阻，以及两颗 MOS 管（焊在转接板上）。
2. 电源线用 22AWG，信号线用 28AWG，线长留 2–3 cm 余量，别绷太紧。
3. ESP32-C3 和洞洞板**整块用高温胶带包好**，贴在外壳内壁、灯带上方。
4. ESP32-C3 上**没有 USB 口的那一头是天线**，朝向塑料堵头，不要被铝壳完全包住，否则 Wi-Fi 会变差。
5. Type-C 母座从内侧对准堵头的方孔，用热熔胶固定，插拔几次确认不晃。
6. 所有焊点套热缩管，所有裸露金属用高温胶带包好，**防止碰到铝壳短路**。

### 第 10 步：合盖和最终测试（见 §8）

## 7. WLED 设置（照抄即可）

WLED 界面是英文的，下面标出了每一项的英文原名。

### 7.1 LED 设置（Config → LED Preferences）

| 设置 | 填什么 |
|---|---|
| 输出 1：类型 | WS281x RGB |
| 输出 1：GPIO / 长度 / 颜色顺序 | GPIO 3；Length 24；颜色不对就把 Color Order 在 GRB / RGB 之间换 |
| 输出 2：类型 | PWM CCT |
| 输出 2：两个 GPIO | 第一个 4（暖白），第二个 5（冷白）。调色温方向反了就对调 |
| 输出 2：Clock | Normal（默认频率在万赫兹级别，没有频闪） |
| Make a segment for each output | 勾选（分段 0 = 背光，分段 1 = 前光） |
| Enable automatic brightness limiter | 勾选 |
| Maximum PSU Current | **270 mA**（WLED 会自动扣掉 120 mA 给主控，剩约 150 mA 给背光） |
| CCT blending | **0%**（不要改成正数，否则中间色温时电流翻倍） |
| Global brightness factor | 100%（插 USB 2.0 口时调到约 50%） |
| Button 0 | GPIO 6，类型 **Push inverted**（TTP223 触摸时输出高电平） |
| Button 1 | GPIO 7，类型 Push inverted |
| Button 2（可选实体按钮） | GPIO 10，类型 Pushbutton |

> 前光的自动限流（brightness limiter）对 PWM 输出不起作用，这是 WLED 的设计，所以前光靠 §5 的限流电阻。
> 如果 WLED 默认把按钮放在别的引脚，按上表改掉。

### 7.2 Wi-Fi（Config → WiFi Setup）

- 只填家里的 2.4 GHz Wi-Fi。
- 连接不稳就把 Max. TX power 改成 8.5 dBm。

### 7.3 预设（主界面 Presets → + Preset）

新建预设时**取消勾选 Use current state**，在 **API command** 里粘贴下表内容，在 **Save to ID** 里填编号。

| ID | 名称 | API command |
|---|---|---|
| 1 | 专注（约 6000K） | `{"on":true,"seg":[{"id":1,"on":true,"bri":255,"cct":255,"col":[[255,255,255,255]]}]}` |
| 2 | 办公（约 5000K） | `{"on":true,"seg":[{"id":1,"on":true,"bri":210,"cct":170,"col":[[255,255,255,255]]}]}` |
| 3 | 阅读（约 4000K） | `{"on":true,"seg":[{"id":1,"on":true,"bri":160,"cct":85,"col":[[255,255,255,255]]}]}` |
| 4 | 夜间（约 3000K） | `{"on":true,"seg":[{"id":1,"on":true,"bri":40,"cct":0,"col":[[255,255,255,255]]}]}` |
| 11 | 背光·护眼暖白 | `{"seg":[{"id":0,"on":true,"bri":80,"fx":0,"col":[[255,180,110]]}]}` |
| 12 | 背光·静态蓝紫 | `{"seg":[{"id":0,"on":true,"bri":110,"fx":0,"col":[[90,60,255]]}]}` |
| 13 | 背光·呼吸 | `{"seg":[{"id":0,"on":true,"bri":110,"fx":2,"col":[[255,120,40]]}]}` |
| 14 | 背光·彩虹 | `{"seg":[{"id":0,"on":true,"bri":110,"fx":9}]}` |
| 20 | 场景循环 | `{"ps":"1~4~"}` |
| 21 | 背光效果循环 | `{"ps":"11~14~"}` |
| 22 | 背光开关 | `{"seg":[{"id":0,"on":"t"}]}` |
| 23 | 夜灯（30 分钟渐暗关灯） | `{"on":true,"nl":{"on":true,"dur":30,"mode":1,"tbri":0}}` |

- `cct` 0 = 全暖（3000K），255 = 全冷（6000K），中间是两路混合，标的色温是大概值。
- 场景里的 `"col":[[255,255,255,255]]` 是把前光分段设成全白。不写这一项的话，前光分段默认是橙色，在某些白光计算模式下前光会不亮。刷机后第一次按场景键，前光就会正常。
- `fx` 0 = Solid（纯色），2 = Breathe（呼吸），9 = Rainbow（彩虹）。想换别的效果，在主界面选好后看效果列表里的名字即可。

### 7.4 按钮动作（Config → Time & Macros → Button actions）

| 按钮 | Short press（短按） | Long press（长按） | Double press（双击） |
|---|---|---|---|
| Button 0（触摸 1） | 0（默认：开 / 关） | 23 夜灯 | 22 背光开关 |
| Button 1（触摸 2） | 20 场景循环 | 21 背光效果循环 | 0 |
| Button 2（实体按钮） | 0（开 / 关） | 23 夜灯 | 22 背光开关 |

- 设了双击后，短按会有约 0.3 秒延迟（在等你是不是要按第二下），属于正常现象。
- 按过“背光效果循环”或“夜灯”之后再按场景键，会从“专注”重新开始，也是正常的。

### 7.5 手机控制

- **不装 App**：手机浏览器打开灯的 IP，然后“添加到主屏幕”，用起来和 App 一样。
- **装 App**：iPhone 在 App Store 搜 WLED；安卓可以从 WLED 官方 GitHub 下载安装包。
- 可以调亮度、色温、背光颜色和效果，设定时开关灯；也能接入 Home Assistant。

## 9. 常见问题

| 现象 | 原因和办法 |
|---|---|
| 网页刷机找不到设备 | 换能传数据的线；按住 BOOT 再插 USB；用 Chrome 或 Edge 电脑版 |
| 连不上 Wi-Fi | 只支持 2.4 GHz；Max. TX power 改 8.5 dBm；天线那头别被铝壳包住 |
| 背光乱闪或颜色不对 | 检查 1N4007 是否装了、方向是否对；数据线是否接在 DIN 端；所有 GND 是否接在一起；Color Order 换成 GRB 或 RGB |
| 调色温方向反了 | LED 设置里 PWM CCT 的两个 GPIO 对调 |
| 低亮度时手机拍有条纹 | Clock 用 Normal 或 Fast；MOS 模块不能用光耦款 |
| 触摸没反应 | 确认按钮类型是 Push inverted；TTP223 接的是 3V3；感应面贴紧塑料；离铝壳远一点 |
| 触摸自己乱触发 | 上电时别碰；模块背面电容焊盘加 10–20 pF；信号线远离 MOS 管和灯带负极线 |
| 插显示器 USB 口一开最亮就重启 | USB 2.0 口只有 500 mA：改插充电头，或把 Global brightness factor 调到 50% |
| 设置改乱了找不到灯 | 灯连不上 Wi-Fi 时会自己打开 WLED-AP 热点，连上去重新设置 |
| 更新固件 | Config → Security & Updates → Manual OTA Update，上传新的 .bin，不用拆灯 |

## 10. 安全

- 整灯是 5V 低压，没有触电危险；主要风险是**短路发热**。铝壳导电，**绝缘是第一要务**。
- 电解电容有正负极（长脚为正），接反会鼓包。
- 二极管有色环的一头是负极，方向接反背光或主控会不亮。
- 第一次通电在桌上进行，用 USB 电流表看着；电流异常大（超过 1 A）立刻拔掉。
- 刷机或插电脑调试时，**先拔掉灯的供电线**，只让电脑给主控供电。
- 灯不要压在电源线上，也不要盖着布长时间开着。
