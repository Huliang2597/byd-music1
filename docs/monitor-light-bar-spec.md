## 0. 结论速览（先回答三条提问）

| # | 提问 / 批注 | 结论 |
|---|---|---|
| 1 | 夹具样式？ | **背挂式重力夹（前挂钩 + 后配重臂 + 中间铰链）**，适配屏厚 0.6–3.0 cm、平面屏和 ≥1000R 曲面屏，不夹压面板；阻尼转轴放在灯体与夹具连接处，灯头俯仰 −10°～+25°。顶部带摄像头平台（1/4" 螺孔）的公模优先。详见 §2。 |

| 3 | 蓝牙 +25、触摸 +20 | 按 BOM 估算，蓝牙模组含授权约 ¥6–9，触摸（IC + 电极 + CNC 开窗）约 ¥2–4。**批注里的成本若是方案商报价，偏高很多，建议要拆分报价。** 硬件设计成**一套 PCB 兼容 按键 / 触摸 / BLE / ARGB 选贴**，可以按 SKU 分开出货。详见 §7.4、§10。 |

**关键设计决策（摘要）**
1. 前光：48 颗双色温 2835（Ra95 料），**8 串 6 并**，接**一路升压恒流**。冷暖两路用**互补 PWM（重叠，不加死区）** 混色，亮度走**模拟（DC）调光**，所以没有频闪，换色温时总光通也不变。
2. 电源：USB-C 只做 5 V Sink（CC 各接 5.1 kΩ 下拉），输入端有软启动加短路保护，分支各有硬件上限，固件用分流电阻闭环测电流，带 VBUS 跌落自适应降额（兼容只给 500 mA 的 USB2 口）。
3. 无线：**只做 BLE，不做 Wi-Fi**。Wi-Fi 发射峰值约 300 mA 以上，会吃掉三分之一的功率预算，而手机控制用 BLE 已经足够。推荐涂鸦 BLE 模组走 MCU 串口协议，不用自己开发 App，上市最快。
4. 触摸：铝壳上做不了电容触摸，要在**右端顶面 CNC 开窗，嵌 PC 触控盖板**（或者用加长塑料端盖，成本更低）。

## 2. 夹具方案（回答提问 1）

### 2.1 公模样式对比

| 样式 | 原理 | 优点 | 缺点 | 结论 |
|---|---|---|---|---|
| **A. 背挂式重力夹**（前挂钩 + 铰链 + 后配重臂） | 重心落在屏幕背面，靠自重挂在屏幕上沿，铰链自适应屏厚 | 不压面板；适配平面/曲面屏；安装一放即可；公模多 | 后配重臂会碰到屏幕背后凸起很大的机型 | **推荐** |
| B. 弹簧夹 | 弹簧夹住屏幕上沿 | 便宜 | 夹持力直接压在面板上，超薄屏、曲面屏容易压伤或漏光；夹持厚度范围小 | 不推荐 |
| C. 粘贴底座 + 磁吸 | 屏幕背面粘底座 | 最稳 | 要用胶，用户接受度低，拆卸会留胶 | 只作配件 |
| D. A 型 + 顶部摄像头平台 | A 型的夹具顶面做成平台，带 1/4" 螺孔 | 解决“挂灯后摄像头没地方放”的痛点 | 夹具贵 ¥1–2 | **A 型的优选款** |

### 2.2 选型要求（给夹具供应商的规格）

| 项目 | 要求 |
|---|---|
| 适配屏厚 | 0.6–3.0 cm（覆盖绝大多数平面屏；曲面屏 ≥ 1000R） |
| 前挂钩 | 下垂深度 ≤ 8 mm（不遮挡窄边框屏的显示区），厚度 ≤ 3 mm，内侧贴防滑硅胶垫（邵氏 40–50A，厚 1 mm） |
| 后配重臂 | 长度 ≥ 60 mm，接触面带硅胶垫；配重用锌合金或铁块，夹具总重 80–120 g |
| 稳定性 | 灯体加夹具的合重心必须落在屏幕前表面之后 ≥ 5 mm；装好后向前推 15° 不翻落 |
| 阻尼转轴 | 轴线平行于灯体长度方向；俯仰 −10°～+25°；扭矩 0.8 ±0.2 kgf·cm（推导见下）；寿命 ≥ 5,000 次后扭矩衰减 ≤ 30% |
| 灯体连接 | 卡箍或卡槽抱住铝型材中段（型材要有对应卡位），不能在铝面上留压痕 |
| 材料 | PC/ABS（UL94 V-2 及以上）+ 锌合金；表面颜色与铝型材一致 |
| 线缆 | USB 线**不穿过转轴**（避免反复扭转断线），从左端盖直接引出，沿屏幕背后走线 |

**阻尼扭矩推导**：灯体约 0.22 kg，绕转轴的重心偏心按 10 mm 估算，重力矩 = 0.22 × 9.8 × 0.01 ≈ 0.022 N·m ≈ 0.22 kgf·cm。取 3–4 倍安全系数（防止碰一下就掉角度，同时手调起来不费劲），得 0.8 ±0.2 kgf·cm。EVT 阶段用实物称重和实测重心后再修正。

## 3. 光学方案（前光）

### 3.1 光源

- **灯珠**：双色温 2835（单颗封装内一颗 3000K 芯 + 一颗 6000K 芯，4 脚），48 颗，间距 8.33 mm。
- **选料要求**：单色温 Ra ≥ 95、R9 ≥ 50。原因：3000K 和 6000K 混出的中间色温会落在普朗克轨迹下方（Duv 偏负），Ra 会掉 2–4 个点，所以单芯要用 95 的料，才能保证全段 ≥ 90。
- **分档**：同一批次同一 Vf 档（档宽 ≤ 0.1 V）、同一色区（3 阶麦克亚当椭圆以内）。Vf 一致决定 6 路并联的均流，色区一致决定整条灯色温均匀。
- **工作点**：单芯约 21 mA（额定 60 mA 的 35%），光效高、温升低、光衰慢。

### 3.2 非对称配光（防屏幕眩光）

挂灯的核心体验：**光只往桌面和键盘区打，不打到屏幕上**。用公模做的实现方式：

1. LED 板在型材里**向用户方向前倾 20°±5°** 安装（型材里要有斜卡槽，选公模时重点核对）。
2. 型材**后侧做 3–5 mm 遮光唇**，挡住射向屏幕的后向光。
3. 前侧做短遮光檐，防止用户直视灯珠（坐姿视线高于灯底面时看不到发光面）。
4. 扩散罩用高雾度 PC（透过率 75–85%，雾度 ≥ 90%）。灯珠到罩的距离 ≥ 6 mm，才能消除 8.3 mm 间距带来的颗粒感。
5. 有条件的可以做微棱镜 PC 罩，压窄光束，更不容易溢光到屏幕上；这属于升级项，要开挤出模。

**验证指标**：显示器 24" 和 27" 两种工况，45 cm 坐姿，屏幕中心照度增量 ≤ 30 lx，熄屏状态下正视屏幕看不到反射光带。

### 3.3 混光与调光原理

```
            ┌────────── 升压恒流 (总电流 I_total 由 DIM 设定, DC 调光) ──────────┐
VBUS 5V ──► │ BOOST ──► V_out ≈ 23 V ──┬── 6 串暖白芯 (8S6P) ── Q_W ──┐          │
            │                          └── 6 串冷白芯 (8S6P) ── Q_C ──┴─ R_sense ─┘
            └──────────────────────────────────────────────────────────────────────┘
   MCU: DIM (PWM→模拟)  → 总亮度
        PWM_W / PWM_C (25 kHz 互补, 重叠 0.2–0.5 µs) → 色温比例 D : (1−D)
```

- **同一时刻只有一路导通**，升压的负载恒定，所以换色温时总功率不变，输入电流不会跳。
- 互补 PWM **用重叠，不用死区**：两路同时关断时恒流环会开路，触发 OVP 尖峰；两路短暂同时导通只是分流，没有坏处。
- PWM 频率 25 kHz：高于可闻频段（陶瓷电容不会啸叫）。暖芯冷芯光效有差别，会带来残余调制，但在这个频率下属于 IEEE 1789 无风险区。
- 亮度用 DC（模拟）调光，1% 以下才切到低频 PWM 补偿，消费者感知层面算“无频闪”。
- **等光通色温**：暖芯光效比冷芯低约 10–15%，固件里存一张色温 → 电流补偿表（产测时校准），保证在 3000K 和 6000K 之间切换时亮度看起来一样。

### 3.4 照度可行性估算

LED 电功率上限 2.8 W，Ra95 料在这个电流下光效约 125 lm/W，得 350 lm；扩散罩加遮光损失约 20%，出光约 280 lm。非对称光束集中在约 60 × 35 cm 的桌面区，利用率按 0.6 计，平均照度约 800 lx，中心 ≥ 500 lx 有裕量。**EVT 阶段要用配光曲线仪实测确认。**

## 4. 背光氛围灯方案（回答提问 2）

### 4.1 要不要做

- **功能价值**：真正有用的是 Bias Light（屏后背景光），它能降低屏幕和暗墙之间的明暗反差，减轻暗室用屏的视疲劳；RGB 灯效主要是电竞桌搭的颜值卖点。
- **建议**：**只在 Pro 版做**。基础版和标准版不贴 ARGB，PCB 和型材共用（背光罩改成同色盲条）。
- **默认模式设为“护眼背光”**：6500K 近似白、10–20% 亮度；RGB 灯效（流水、呼吸、静态色）作为可选模式。

### 4.2 位置

```
          用户 ◄────────── 前                     后 ──────────► 墙
                       ┌──────────────────────────┐
                       │      铝型材 (顶面)        │  ╲ 背光 PC 罩
          遮光檐 ─┐     │                          │   ╲  ARGB 朝后上方 30–45°
                  └──── │  前倾 20° LED 板          │    ↗↗  打亮显示器后方墙面
                       └──┬──── 扩散罩 ────┬──────┘
                          ↓↓  光打向桌面    └ 后遮光唇（挡屏幕方向的光）
                    ═══════════ 显示器上沿 ═══════════
```

- 在灯体**背面**开一条独立灯槽（要求公模是“双面出光”型材，**选型时必须确认**），装 ARGB FPC 和乳白 PC 罩。
- 朝向后上方 30–45°：光打到显示器后上方的墙面，用户坐姿看不到灯珠，也不会照进眼睛或打到屏幕上。
- 灯珠：WS2812B-2020（2 × 2 mm，适配窄槽），20 颗，间距 20 mm，覆盖 400 mm。

### 4.3 功率问题怎么解决

你的判断是对的：WS2812B 单颗全白约 60 mA（每通道约 20 mA），20 颗全白就是 1.2 A，单这一路就超过整机预算。方案如下：

1. **硬件封顶**：ARGB 的 5 V 走一颗**可调限流负载开关**（TPS2553 / SY6280 类，限流设定 ≈160 mA，最大 ≤180 mA）。固件失效时 ARGB 也吃不到 180 mA 以上。关闭氛围灯时直接断电，顺带消掉 20 颗灯珠的静态电流（约 10–20 mA）。
2. **固件封顶 150 mA**：固件按 `I ≈ N × I_q + Σ(R+G+B)/255 × I_ch` 估算电流（I_ch 产测时标定），超出就整体等比缩放亮度。
3. **能做到的亮度**：150 mA 扣掉静态电流后约 135 mA 可用，相当于全白约 11%、单色约 34%。作为背景光这已经够亮；墙面亮度太高反而会刺眼。
4. **如果市场要求更亮的 ARGB**（待确认）：可以换成“ARGB 硬件限流 300 mA + 前光硬件上限降到 2.3 W”的配置，代价是前光照度下降约 18%。不建议这样做。

### 4.4 电平兼容（容易踩的坑）

WS2812B 在 5 V 供电时 VIH = 0.7 × VDD = 3.5 V，**3.3 V 的 MCU 直接驱动处在临界区**，低温或者 VBUS 偏高时会乱码。必须加一颗 **74AHCT1G125**（5 V 供电，TTL 输入电平），串 33 Ω 电阻后再进第一颗灯。每颗灯珠旁放 100 nF 去耦电容。

## 5. 电源架构与功率预算（核心）

### 5.1 USB-C 输入

| 项目 | 设计 |
|---|---|
| 角色 | Sink only，CC1 / CC2 各接 **5.1 kΩ 下拉（Rd）**。不接的话 C-to-C 线插充电头不会出电，这是最常见的设计缺陷 |
| 连接器 | 6P 或 16P 卧式 Type-C 母座，插拔寿命 ≥ 10,000 次（6P 只有 VBUS/GND/CC，够用且更便宜） |
| 来源识别 | MCU 的 ADC 读 CC 电压：0.25–0.61 V 为 Default USB，0.70–1.16 V 为 1.5 A，1.31–2.04 V 为 3.0 A。即使检测到 1.5 A 或 3 A，**也按规格封顶 900 mA** |
| 浪涌 | USB 规范要求上电瞬间 VBUS 端容值 ≤ 10 µF：VBUS 口只放 4.7 µF，后级大电容放在带软启动的负载开关后面 |
| 保护 | VBUS 上放 TVS（5 V 单向，如 SMF5.0A），CC 和 D± 上放 ESD 阵列；输入负载开关带软启动和短路保护（约 1.1 A 动作，自动重试） |
| 电流检测 | 50 mΩ 分流电阻 + INA180A2（增益 50）→ ADC，900 mA 对应 2.25 V；分流电阻损耗 40 mW |
| 电压检测 | VBUS 经 100k/100k 分压 → ADC |

### 5.2 “硬件 + 固件 ≤ 900 mA”的实现

**这里需要统一对规格的理解**：在输入端放一个精确卡在 900 mA 的 eFuse，会因为器件 ±10% 的公差频繁误动作（用户看到的就是灯一闪一闪）。所以本方案这样实现“硬件限流 ≤ 900 mA”：

> **每条支路各自有硬件上限，最坏工况（VBUS 4.75 V、固件跑飞）下三路合计 ≤ 900 mA**；输入负载开关只负责短路保护；固件闭环把稳态电流控制在 850 mA 以内。

| 负载 | 硬件上限手段 | VBUS = 5.00 V | VBUS = 4.75 V |
|---|---|---|---|
| 系统（MCU + BLE + 触摸 + LDO + 指示灯） | — | 20 mA | 20 mA |
| 前光（LED 2.8 W 输出 + 镇流 0.05 W，升压 η ≈ 87%） | R_sense 定死 LED 最大电流 | 655 mA | 690 mA |
| 背光 ARGB（Pro） | 限流开关 ≤ 180 mA | 150 mA（固件上限） | 150 mA |
| **合计，固件正常** | | **825 mA / 4.13 W** ✓ | 860 mA → 固件把前光压到约 98%，回到 850 mA |
| **合计，固件失效最坏** | | 855 mA ✓ | **890 mA ✓（≤ 900）** |

推导：前光输入功率 = (2.8 + 0.05) / 0.87 = 3.28 W；在 5.00 V 下为 655 mA，在 4.75 V 下为 690 mA。

### 5.3 固件功率仲裁

- 10 ms 周期读一次输入电流，PI 闭环。目标 ≤ 850 mA，优先级：**系统 > 前光 > ARGB**（用户主动调 ARGB 时，先在 ARGB 自身 150 mA 上限内缩放，不去抢前光）。
- **VBUS 跌落自适应（兼容 USB2 口 500 mA）**：显示器上的 USB-A 口很多是 USB2（500 mA），线里的 56 kΩ 上拉只能告诉设备是“Default”，区分不了 500 mA 和 900 mA。所以：
  - VBUS < 4.60 V 持续 200 ms：前光每 100 ms 降 5%，直到 VBUS 回到 4.65 V 以上；
  - VBUS < 4.40 V：直接进入 **500 mA 兼容档**（前光 ≤ 380 mA，约 58% 亮度；ARGB ≤ 80 mA），指示灯慢闪 3 次提示；
  - 兼容档会被记住，下次上电按兼容档启动，30 s 后再试探性升档。
- 用户也能手动切“低功耗模式”（App 开关，或 K1 + K3 长按 3 s）。
- **过温**：LED 板中部放 NTC，> 65 °C 开始线性降额，> 80 °C 关前光（按估算，正常不会触发）。

### 5.4 电源树

```
USB-C VBUS ─ TVS ─ 分流 50 mΩ ─ 输入负载开关(软启动/短路保护) ─┬─ 升压恒流 ── 前光 8S6P ×2 路
                                                              ├─ 限流开关 ≤180 mA ── ARGB ×20 (Pro)
                                                              └─ LDO 3.3 V (ME6211) ── MCU / BLE / 触摸 / 运放
```

- 3.3 V 支路只有约 20 mA，用 LDO（ME6211C33）就够，比 Buck 便宜也更安静。**如果以后要做 Wi-Fi 版，必须换 Buck**（Wi-Fi 峰值 300 mA 以上）。
- **关灯微亮（鬼火）**：升压关断后 VOUT ≈ VBUS ≈ 5 V，而 8 串 LED 的 Vf ≈ 23 V，所以完全不会导通，从拓扑上消除了鬼火。

### 6.3 LED 铝基板

- 尺寸 400 × 8–10 mm（宽度按型材卡槽定），1.0 mm 厚铝基，导热 ≥ 1.0 W/m·K，单面；白油。
- 走线：每颗双色温灯珠的暖芯和冷芯分属两路；6 个并联串**按空间交错排布**，这样即使某一串偏暗，也是均匀分散的，不会出现一段暗区。
- 每串串 20 Ω 镇流电阻（20 mA 时压降 0.4 V，功耗 8 mW），配合同一 Vf 档，均流误差可以压到 ±5% 以内。
- 端子：两端焊盘直接焊线（或板对线连接器）接电源板，NTC 信号也走这条线。

### 6.4 PCB 设计要点 checklist

- [ ] 升压环路（开关管 → 电感 → 二极管 → 输出电容 → 地）面积最小，地平面完整，FB 走线远离电感。
- [ ] R_sense 用开尔文连接；用 1% 精度；它决定硬件上限，BOM 里标成**关键件，禁止替代**。
- [ ] CC 下拉 5.1 kΩ 用 1%。
- [ ] 触摸电极：8 × 8 mm，键间距 ≥ 15 mm，电极距离铝壳 ≥ 3 mm，触摸走线最短，不与 PWM 走线平行；敷铜用网格地。
- [ ] 铝壳通过 USB 外壳接 GND（ESD 泄放路径），触摸 IC 的灵敏度在装壳后标定。
- [ ] 控制板上 BLE 天线的净空区（按模组手册）要对准塑料件区域，**不能被铝壳包住**（天线位置放到触控窗或端盖下方，否则距离会掉到 1–2 m）。
- [ ] 预留 SWD、UART 测试点，以及产测针床定位孔。

## 7. 操控与交互

### 7.1 触摸区位置

铝是导体，**没法隔着铝壳做电容触摸**。两个方案：

| 方案 | 做法 | 成本 | 外观 |
|---|---|---|---|
| **A（推荐）** | 右端顶面 CNC 铣窗 70 × 10 mm，嵌入 1.5 mm 厚 PC 触控盖板（背面丝印图标，透光孔下面放指示灯） | CNC ¥1–2 + 盖板 ¥0.5 | 一体感强，接近一线品牌 |
| B（降本） | 右端盖加长做成 30 mm 的塑料件，触摸键做在端盖顶面 | ≈ ¥0 增量（改端盖模） | 端盖较长，按键较挤 |

基础版：同一位置换成实体按键盖板，下面放 4 颗 3 × 4 mm 侧按/顶按轻触开关（寿命 ≥ 100,000 次）。

### 7.2 按键定义（触摸版与实体按键版逻辑一致）

| 键 | 短按 | 长按 | 其他 |
|---|---|---|---|
| K1 ⏻ 电源 | 开/关（300 ms 渐变） | 5 s：进入 BLE 配网（指示灯快闪） | K1 + K2 长按 8 s：恢复出厂 |
| K2 ☀ 亮度 | 循环 20 / 50 / 80 / 100% | 无级调光，每次长按方向交替，到顶/到底闪一下 | — |
| K3 🌡 色温 | 循环 3000 / 4000 / 5000 / 6000K | 无级调色温，方向交替 | K1 + K3 长按 3 s：低功耗模式开/关 |
| K4 ✦ 氛围灯（Pro） | 开/关 | 调氛围灯亮度 | 双击：切换模式（护眼背光 → 静态色 → 呼吸 → 流水） |

- **防误触**：按住 50 ms 才判定有效；≥ 3 个键同时触发视为擦拭或手掌误触，直接忽略；上电后 1 s 内触摸 IC 自校准，期间不响应。
- **指示灯**：每键下面一颗 0603 暖白 LED，≤ 1 mA，开灯后 5 s 自动降到 10% 亮度（避免夜间刺眼），可以在 App 里关掉。

### 7.3 手机端（BLE）

**推荐方案：涂鸦 BLE 模组 + MCU 串口协议**（MCU 负责全部灯控逻辑，模组只做透传和云端/App 对接）。

- 优点：不用开发 App（用“涂鸦智能 / 智能生活”App，也可以做自有品牌 OEM App）；自带 OTA、定时、场景；可以接入涂鸦生态的语音音箱联动（通过网关）。
- DP 点规划（参考涂鸦照明品类标准 DP，以平台最新定义为准）：

| DP | 功能 | 类型 | 范围 |
|---|---|---|---|
| 20 switch_led | 前光开关 | bool | — |
| 21 work_mode | 模式（白光/场景） | enum | white / scene |
| 22 bright_value | 前光亮度 | value | 10–1000 |
| 23 temp_value | 色温 | value | 0–1000（映射 3000–6000K） |
| 25 scene_data | 场景（阅读/办公/观影/夜间） | string | — |
| 26 countdown | 倒计时关灯 | value | 0–86400 s |
| 自定义 | 氛围灯开关 / 模式 / 颜色 / 亮度 / 速度 | bool / enum / string / value | — |
| 自定义 | 低功耗模式、指示灯开关、休息提醒（每 45 min 闪一下提醒起身） | bool / value | — |

- 备选方案 1：ESP32-C3 单芯片（BLE 加可选 Wi-Fi）加自研小程序/App，适合要做自有生态的情况，开发周期多 6–8 周。
- 备选方案 2：米家生态，需要走小米认证和合作流程，周期长，适合有渠道资源的情况。

## 12. 生产与产测

### 12.1 工艺流程

```
来料检验 (LED 分档/夹具扭矩/型材尺寸与膜厚) → SMT (LED 铝基板, 电源板, 控制板)
→ MCU 烧录 + BLE 授权写号 → 板级 ICT/FCT → 总装 (板入型材, 罩, 端盖, 盖板)
→ 整机 FCT → 老化 (满功率 4 h, 循环开关) → 整机复测 → 外观检 → 包装 (夹具分装)
```

### 12.2 整机 FCT 治具（每台都测，单台节拍 ≤ 30 s）

1. 4 个工况下输入电流（关灯 / 3000K 100% / 6000K 100% / Pro 版前光 100% + ARGB 全白），和标准值比较，偏差 ±5%。
2. 照度和色温点检：治具暗箱里放照度计 + 色彩传感器，测 3000K 和 6000K 两点，并**写入等光通补偿系数**。
3. ARGB：相机或色彩传感器检测 R / G / B / 白四种画面，确认无死灯。
4. 触摸：铜柱模拟手指逐键点按，读取触摸 IC 的原始值，确认在窗口内。
5. BLE：读 RSSI，确认在标准值 ±6 dB 以内，并确认授权码写入成功。
6. 掉电记忆：设置后断电再上电，确认状态正确。

### 12.3 关键质量控制点

- LED：每批核对 Vf / 色区分档标签，**禁止混档**；首件做积分球测试。
- R_sense、CC 下拉电阻、限流开关的限流电阻列为关键件，替代必须走 ECN 并重测 §11.2 的电流项。
- 夹具：每批抽检扭矩（0.8 ±0.2 kgf·cm）和挂钩下垂深度。
