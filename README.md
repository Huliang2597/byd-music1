# 曲库共建（WikiUploader）

网易云音乐曲库共建客户端：补充缺失专辑、完善歌曲资料与歌词、领取云小编任务、修改艺人资料，以及无需登录的歌曲百科查询。

本仓库是 1.1.6 (107) 版本的 Kotlin + Jetpack Compose 重建版（当前 1.2.3），功能与接口逻辑保持一致，界面全部重新设计并加入了过渡动画。

## 功能

| 页面 | 内容 |
| --- | --- |
| 专辑 | 识别艺人链接 / ID 或搜索艺人，填写专辑信息，封面自动生成原图与 1:1 图并上传，批量选择音频立即分片上传，逐首编辑歌曲资料后提交审核 |
| 歌曲 | 按歌名、ID、分享链接或 163cn.tv 短链接找歌；编辑基本信息、创作者、歌词与翻译（提交前调用歌词校验）、报告并替换音频；按字段权限禁用不可修改项 |
| 任务 | 推荐 / 歌曲 / 专辑 / 艺人 / MV / 歌词 / 我的；任务组详情支持搜索、语种筛选、分页；认领后「去完成」直接跳到歌曲编辑 |
| 百科 | 公开歌曲百科查询（无需登录），创作者、贡献记录、查询历史；顶部进入「艺人资料修改」 |
| 我的 | 账号信息、贡献数与积分、我的贡献（类型 + 审核状态筛选、分页）、接口通道（自动 / eapi / weapi）、退出登录 |
| 登录 | 扫码登录、Cookie 登录、网易云官网网页登录 |

## 界面与动效

- 统一的玫红 → 珊瑚 → 紫色品牌渐变，浅色 / 深色两套配色，圆角卡片与分区标题
- 悬浮式底部导航：五个固定宽度的导航项，选中时只渐变胶囊底色和文字颜色，不改变尺寸
- 页面切换淡入淡出；二级页面（歌曲编辑、任务组详情）推入 / 返回动画，支持系统返回手势
- 列表项错位淡入，增删时位移动画；专辑歌曲卡片点击展开编辑
- 加载骨架屏流光、空状态 / 错误状态插画、按钮按压轻微缩放、上传渐变进度条、统计数字滚动
- 艺人资料编辑页从底部滑入；图片裁剪支持拖动、双指缩放，带三分线与头像圆形参考
- 系统关闭动画（开发者选项里的动画缩放为 0）时自动跳过入场动效

## 构建

需要 JDK 17+ 与 Android SDK（compileSdk 35）。

```bash
echo "sdk.dir=/path/to/android-sdk" > local.properties
./gradlew :app:assembleRelease      # 输出 app/build/outputs/apk/release/app-release.apk
```

release 构建默认使用调试签名，便于直接安装测试；正式发布前请在 `app/build.gradle.kts` 里换成自己的签名配置。由于签名不同，新包无法覆盖安装旧版，需要先卸载旧版。

## 测试

```bash
./gradlew :app:testDebugUnitTest                 # 解析逻辑单测 + 界面截图渲染
./gradlew :app:recordPaparazziDebug              # 重新生成界面截图到 app/src/test/snapshots/images
./gradlew :app:testDebugUnitTest -Pnetwork=true  # 额外执行联网自检（weapi 扫码、eapi 搜索、公开百科）
```
