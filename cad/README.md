# 显示器挂灯 · 3D 打印件

- `monitor-light-bar.scad`：参数化模型。用 OpenSCAD 打开，菜单「窗口 → 定制器」里填铝槽和显示器尺寸，选零件，按 F6 渲染后导出 STL。
- `stl/`：默认尺寸（铝槽 25 × 15 mm、显示器厚 15 mm）导出的 STL，已摆好打印方向。尺寸不一样必须重新导出。
- `preview/`：默认尺寸的渲染预览图。

零件清单、打印设置、怎么量尺寸、试配件用法，见 [`docs/diy-monitor-light-bar.md`](../docs/diy-monitor-light-bar.md) 第 2 节。
