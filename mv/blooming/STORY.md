## 视觉语言（参考同曲 ADOFAI 特效谱的叙事手法，effectpv.py）

不是把画面做成 ADOFAI，而是借特效谱「每句歌词一幕」的讲故事方式：

- **宽银幕遮幅**：上下黑边，整段像电影。
- **一句一幕、单色调**：每句（或半句）歌词换一个场景和色调，切换时落一个过曝白闪。
  | 歌词 | 场景 | 剧情 |
  | --- | --- | --- |
  | 泣き虫の | 褐色雾、花草剪影、落叶般的花瓣 | 两朵玫瑰（我、君）在雾里并肩 |
  | 雨が降る | 灰雨 + 光束 | 「君」那朵的花瓣被雨打散，顺着光束飘上天，花头谢去；「我」那朵在雨里低下头 |
  | 心の花で | 纯黑白、圆相（ensō） | 一朵墨线玫瑰从花苞一圈圈开到盛放 |
  | 満開の瞬間 | 粉米色曼陀罗 + 放射光 + 花瓣炸开 | 同一朵花第一次有了颜色 |
  | 遠い星が微笑む | 冰蓝星空、发光的玫瑰和草 | 天上最亮的那颗星带一点粉色，就是「君」；唱到「微笑む」时星光一闪 |
  | 寄り添う愛 | 黑底白线稿：藤蔓和叶子一笔笔画出来 | 两朵线稿玫瑰一笔笔画出来，靠在一起 |
  | 永遠の歌 | 白纸、五线谱、灰色水彩花 | 每一拍谱上多一个音符：走过的路变成了歌 |
  | 尾声 | 五线谱平息成金色丝带，封面的六芒星徽章，logo 和 credits | — |
- **毛笔大字**：日文歌词用 Yuji Syuku 毛笔体，一次一两个词，出现时带一圈放大消散的描边残影；暗场景用描边加光晕。
- **小号手写翻译**：底部居中，中文（Long Cang）。
- **贯穿元素**：流动的丝带、画面中央的细圆环（随拍子脉冲）。不用光球，「我」和「君」由两朵玫瑰来演。
- **花**：全部是 rose.py 画的矢量玫瑰（螺旋花心、层层圆瓣、外卷瓣尖、径向渐变），同一套造型出墨线、上色、线稿、水彩、冰色几种版本。

## 全屏插画版（keyart.py，当前方案）

矢量版太像剪贴画，缺质感。现在改成：封面用 Real-ESRGAN 动漫模型放大 4 倍（upscale.py），每句歌词是封面上的一个镜头，
分场景调色后做缓推/摇镜和手持微晃，叠光束、雨、粒子、虚化光斑，再过合成后期（post.py：泛光、色差、颗粒、暗角）。

| 歌词 | 镜头（封面上的位置） | 调色 | 剧情 |
| --- | --- | --- | --- |
| 泣き虫の | 双眼特写，眼角聚起一滴泪滑落 | 褐 | 爱哭鬼是她 |
| 雨が降る | 从脸摇到花束，雨 + 光束，花瓣往上飘 | 灰 | 雨 = 眼泪 |
| 心の花で | 一朵白玫瑰特写，墨从中心晕开，圆相 | 纯黑白 | 心之花 |
| 満開の瞬間 | 白闪后急速拉远到整束花，曼陀罗 + 放射光 + 花瓣炸开 | 粉米 | 满开 |
| 遠い星が | 左上角的星饰，最亮那颗加星芒 | 冰蓝 | 远方的星 |
| 微笑む | 从发间玫瑰摇到她的眼睛，星光一闪 | 冰蓝 | 星星在微笑 |
| 寄り添う愛 | 封面提取的白色线稿，从左往右显影 | 黑底白线 | 贴近的爱 |
| 永遠の歌 | 淡水彩的封面 + 五线谱逐拍长出音符 | 纸色 | 永恒的歌 |
| 片尾 | 第一次露出全彩的完整封面 + logo + credits | 全彩 | 花开的星球 |

## 参考特效谱复刻版（refpv.py + reftex.py，当前方案）

照用户给的 12 张参考截图逐镜复刻，不含方块路和光球：
泣き虫の = 暖褐过曝 + 横向光条 + 细弧线 + 金色浮尘；雨が降る = 灰雾 + 顶光光束 + 小圆环；
心の花で = 黑底 + 圆环 + 细长白色花茎上的一朵白花，唱到「花で」时茎折断、花头回弹着垂下、花瓣掉落；満開の瞬間 = 灰粉底 + 曼陀罗线稿 + 中心白光 + 残影字；
遠い星が = 冰蓝 + 飘雪 + 发光冰霜植物 + 描边「星」；微笑む = 深蓝星空 + 带横向星芒的亮星；
寄り添う愛 = 黑底白线稿叶子 + 细丝带；永遠の歌 = 白纸 + 大高音谱号 + 宽五线谱带 + 音符 + 水彩牡丹；
片尾 = 青灰雾 + 深色丝带 + 虚化花影 → 白色星徽 → credits → 双行 Blooming Planet logo。

动效：歌词逐字由虚到实浮现（约 0.8 秒）、停留时缓慢上漂并展开字距、出场虚化淡出；字幕上下句交叉淡变；
场景之间 0.56 秒交叉溶解 + 柔和曝光（不再硬切）；每一幕匀速缓推/平移/微旋；节拍脉冲用先起势再回落的平滑包络。

v3 动效：转场按场景选（虚焦溶解 / 经暗场 / 中心柔光扩散 / 推进穿越 / 上下漂移溶解，约 1 秒），不再全屏白闪；
歌词按半拍逐字自上而下墨写显影、各自浮动、随拍微光、离场逐字散开虚化；泛光与光效整体降低避免过曝，开头从黑场淡入；
大音符弹入后随拍起伏摇摆，另有小音符沿五线谱持续流动。
